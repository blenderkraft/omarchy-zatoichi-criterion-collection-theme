# Zatoichi Criterion Collection

A dark Omarchy theme. Each Criterion cover sits centered on a 16:9 canvas with black bars, so the art and title band stay whole. The desktop is charcoal, with a cinnabar accent and a teal complement.

Install:

```bash
omarchy theme install https://github.com/blenderkraft/omarchy-zatoichi-criterion-collection-theme
```

The covers are Criterion Collection artwork. This repo shares them as wallpapers for the theme.
