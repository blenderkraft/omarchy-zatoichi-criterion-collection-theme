# Zatoichi Criterion Collection

A dark Omarchy theme. Each Criterion cover sits centered on a 16:9 canvas with black bars, so the art and title band stay whole. The desktop is charcoal, with a cinnabar accent and a teal complement.

The wallpapers are the covers from the original Zatoichi film series. Zatoichi (座頭市) is a blind masseur, gambler, and swordsman created by novelist Kan Shimozawa. Daiei Film and actor Shintaro Katsu turned him into one of Japan's longest-running screen characters. Katsu played him in 26 films from 1962 to 1989. The first was in black and white. The third, in 1963, was the first in color. The 25th arrived in 1973. After a 16-year gap, Katsu wrote and directed the last one himself in 1989. A television series followed the films from 1974 to 1979, 100 episodes from Katsu Productions. Later versions include the 1989 American remake Blind Fury and Takeshi Kitano's 2003 film, which won the Silver Lion for Best Direction at Venice.

Source: [Zatoichi](https://en.wikipedia.org/wiki/Zatoichi) on Wikipedia.

Install:

```bash
omarchy theme install https://github.com/blenderkraft/omarchy-zatoichi-criterion-collection-theme
```
